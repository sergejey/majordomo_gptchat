# GPT Chat

Модуль системы MajorDoMo для работы с сервисами языковых моделей и получения текстового результата по заданным входящим данным.

Варианты использования:
- Интерпретация и разъяснение показаний из различных систем Умного Дома
- Выдача рекомендаций по входящим данным
- Запрос команд на исполнение для управления оборудованием Умного Дома

Группа обсуждения модуля: https://t.me/mjd_gpt_chat

## Основные возможности модуля

Поддерживаемые сервисы:
- Yandex GPT
- Open AI (Chat GPT)
- Claude (Anthropic)
- Gemini (Google)
- DeepSeek
- Kimi (Moonshot)
- Qwen (DashScope)
- Любой OpenAI-совместимый endpoint через «Custom OpenAI compatible API URL»

Для новых провайдеров задайте ключ в настройках модуля и используйте в чате модель с соответствующим префиксом: `claude-*`, `gemini-*`, `deepseek-*`, `kimi-*`, `qwen-*`.

## Особенности API разных провайдеров

Модуль учитывает форматы запросов и ответов:

| Провайдер | Формат запроса | Ответ | Системная инструкция | Изображения |
|---|---|---|---|---|
| OpenAI / Custom / DeepSeek / Kimi / Qwen | `chat/completions`, `messages[]` | `choices[0].message.content` | `role: system` | OpenAI/Custom — да, остальные — нет |
| Yandex GPT | `modelUri` + `completionOptions` | `result.alternatives[0].message.text` | `role: system` | через отдельный сценарий |
| Claude | `messages[]` + `system` сверху | `content[0].text` | отдельное поле `system` | нет |
| Gemini | `contents[].parts[]`, `generationConfig` | `candidates[0].content.parts[0].text` | добавлена к тексту запроса | нет |

Ограничения:
- изображения сейчас передаются только в OpenAI и Custom OpenAI-совместимый endpoint (формат `image_url`);
- для Claude/Gemini/DeepSeek/Kimi/Qwen изображение игнорируется — в лог пишется предупреждение;
- `temperature` ограничен диапазоном 0–1, что подходит всем указанным API;
- максимум токенов ответа: 1000 для Yandex и Claude, 1000 для Gemini, для OpenAI-совместимых — по умолчанию провайдера.

Для работы модуля небходимо получить системные ключи авторизации запросов и прописать их в настройки модуля.

## Изображения: анализ и генерация

Раздел «Зображення: аналіз і генерація» работает с файлами из `cms/images/` и `cms/cached/`:

- **Анализ** — OpenAI (gpt-4o-mini с `image_url`) или Gemini (inline_data): модель описывает содержимое, ответ добавляется в запрос;
- **Генерация** — OpenAI `gpt-image-1` или Gemini Imagen 3, результат сохраняется в `cms/images/` и показывается превью;
- **Сцена** — в промпте можно задать желаемый размер (ширина/высота) и описать визуализацию данных датчиков: температуру, освещённость, статусы устройств;
- изображение можно передать и в обычный запрос чата через `api()` — параметр `image` с путём к файлу.

Ориентировочная стоимость указана в USD в самом разделе: анализ ~$0.0001–0.0002 за изображение, генерация ~$0.01–0.04 за картинку.

Возможности:
- Создание множества чатов
- Базовая настройка чата
  - Название
  - Выбор модели AI из доступных
  - Ручная активация (по ссылке, из кода, с передачей параметров)
  - Активация по изменению свойства связанного объекта
- Настройка запроса
  - Установка инструкции для AI (с использованием параметров)
  - Установка запроса для AI (с использованием параметров)
  - Использование кода подготовки запроса (опционально)
- Настройка обработки результата
  - Использование кода обработки ответа (опционально)
  - Произношение ответа вслух (опционально)
 
## Вызов из сценариев

Отдельный сценарный API не нужен: чат можно активировать через API модуля. Параметры подставляются в `%плейсхолдеры%` в инструкции и запросе чата.

Из сценария через `callAPI()`:

```php
callAPI('/api/module/gptchat?id=1&title=Кухня');
```

Из кода объекта или метода:

```php
$chat = getModule('gptchat');
$chat->api(array('id' => 1, 'title' => 'Кухня'));
```

Метод `api()` принимает `id` чата и любые дополнительные параметры; параметр `image` задаёт путь к файлу для анализа изображения.

### Рецепт: объяснение погоды для детей

Создайте чат с инструкцией «Объясни ребёнку погоду простыми словами» и запросом «Температура %SENSOR_VALUE% градусов». Затем в сценарии:

```php
$value = gg('Sensor.temphum06.value');
callAPI('/api/module/gptchat?id=1&title=Погода&SENSOR_VALUE=' . urlencode($value));
```

Ответ появится в истории чата. Чтобы получить его программно, добавьте в инструкцию чата прескрипт, который разбирает ответ и записывает результат в переменную через `setGlobal()`.

### Рецепт: управление освещением по датчику

Создайте чат с инструкцией «Если показание больше 500 — отвечь "выключить", иначе отвечь "включить"» и запросом «Датчик: %SENSOR_VALUE%». В методе объекта:

```php
$chat = getModule('gptchat');
$chat->api(array(
    'id' => 2,
    'SENSOR_VALUE' => gg('RoomSensor1.value'),
    'title' => 'Освещение'
));
```

### Рецепт: аудит кода из редактора MajorDoMo

Если установлена версия модуля с методом `auditCode()`, редактор кода вызывает его по Ctrl-Shift-A. Настройте чат с названием «Audit» или задайте константу `SETTINGS_CODEEDITOR_GPTCHAT_ID` с его номером.

 ## Примеры использования
 
 **Объяснение погоды для детей**
 
 Инструкция:
 
 *Ты воспитательница детского сада и обращаешься к детям, рассказывая какая погода на улице исходя из температуры воздуха. Кроме того, ты советуешь, что одеть на улицу, чтобы им было комфортно. Постарайся быть краткой, не формальной и избегай примеров и лишней дополнительной информации.*
 
 Шаблон запроса:
 
 *Температура воздуха %Sensor_temphum06.value% градусов.*
 
 Пример ответа (модель yandexgpt):
 
 *Сегодня на улице очень жарко, температура воздуха 37.4 градусов. Поэтому одевайтесь полегче, чтобы не было жарко и вы могли весело играть на прогулке. Не забудьте взять с собой головные уборы, чтобы защитить голову от солнца.*
 
  **Управление освещением в комнате**
  
   Инструкция:
 
 *Ты система управления освещением в комнате. Тебе передаётся значение датчика освещения. Значение более 500 означает, что в комнате светло, иначе в комнате темно. Если в комнате темно, то ты должна ответить одной командой: включить свет. Если в комнате светло, то отвечать командой не нужно. В начале ответа используй команду. После команды поставь символ "=" и кратко объясни, на каком основании было принято решение.*
 
 Код подготовки запроса:
 ```php
 $out['SENSOR_VALUE']=gg('RoomSensor1.value');
 ```
 
 Шаблон запроса:
 
 *Показание датчика освещения %SENSOR_VALUE%.*
 
 Пример ответа (модель gpt-4o):
 
 *включить свет = Показание датчика освещения 5, что означает, что в комнате темно.*
